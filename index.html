How it works

Branch on mode, render three ways.

<Root mode> swaps the wrapper that sets Unlayer's render mode. Everything is composed from Elements' fixed blocks under strict Body → Row → Column → item nesting — the same tree, three outputs.

export default function Cadence({ mode }) {
  if (mode === 'email')    return <Root mode={mode}>{/* teaser        */}</Root>;
  if (mode === 'document') return <Root mode={mode}>{/* frame-it poster*/}</Root>;
  return                     <Root mode={mode}>{/* scroll-story   */}</Root>;
}
